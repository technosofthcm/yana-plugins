# yanagrid-events

Auto-triggers on questions about the YanaGrid JavaScript event API: `addOnLoad`, `addOnChange`, `addOnSave`, `addOnNew`, `addOnNewForm`, `addOnQuickView`, `addOnRowSave`, `addOnRowDelete`, cell manipulation via `EditableGrid` / `Row` / `Cell`, and installing the `Technosoft.Yana.Grid.js` WebResource.

Also triggers on generic discovery queries: "what events can I use with yana grid", "list events", "subscribe to events", "programmatic API", and any mention of `getEditableGrid`, `YanaEditableGrid`, `executionContext`, or `form script`.

Also triggers on the v1.5.0 JS surface: option-set choice filtering (`getOptions`, `addOption`, `removeOption`, `clearOptions`, `resetOptions`, dependent choice), custom command buttons (`addButton`, `removeButton`, `setButtonDisabled`, `setButtonVisible`, `addOnButtonClick`, `removeOnButtonClick`), and cell styling (`setTextFormat`, `setIcon`).

Does NOT cover manifest properties, config XML, or install/deploy steps (separate skills).
