# yanaquickview-install

Auto-triggers on YanaQuickView installation, embedding, and deployment questions, including seeding `xts_pluginconfiguration` records.

Keyword anchors: `install YanaQuickView`, `embed QuickView`, `standalone QuickView`, `QuickView form binding`, `seed xts_pluginconfiguration QuickView`, `QuickView solution import`.

Also answers "how do I install the plugin / what does it ship?" questions via `plugin-install.md`. Does NOT cover manifest property semantics or functional how-to.
