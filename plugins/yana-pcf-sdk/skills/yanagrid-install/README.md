# yanagrid-install

Auto-triggers on YanaGrid installation, form-binding, deployment, and migration questions.

Keyword anchors: `install YanaGrid`, `deploy YanaGrid`, `sub-grid binding`, `home grid binding`, `import TechnosoftDmsCoreComponents`, `solution import`, `WebResource install`, `Technosoft.Yana.Grid.js install`, `migrate from legacy`, `TechnosoftDmsCoreGrid uninstall`.

Also answers "how do I install the plugin / what does it ship?" questions via `plugin-install.md`. Does NOT cover manifest property semantics or the JavaScript event API.
