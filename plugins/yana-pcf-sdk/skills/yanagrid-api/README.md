# yanagrid-api

Auto-triggers on YanaGrid manifest property lookups, behavior contract questions, configuration XML queries, error message lookups, and compatibility/limitations questions.

Keyword anchors: `footerAggregateColumns`, `calculationFormulas`, `parentUpdateFormulas`, `enableGroupBy`, `readOnlyColumns`, `readOnlyStatus`, `autoSaveRecord`, `Formula.`, `xts_pluginconfiguration`, `error code`, `Quick View toolbar configuration`.

Does NOT trigger on JavaScript event questions — those route to `yanagrid-events`. Does NOT cover install steps — those route to `yanagrid-install`.
