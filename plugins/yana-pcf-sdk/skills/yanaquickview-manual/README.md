# yanaquickview-manual

Auto-triggers on YanaQuickView functional questions and version history: features overview, accordion behavior, fullscreen, end-user limits, and release notes / changelogs.

Keyword anchors: `what does YanaQuickView do`, `QuickView features`, `reading sections`, `accordion expansion`, `fullscreen QuickView`, `QuickView release notes`, `QuickView v1.0`, `retry parallel load`.

Does NOT cover manifest property syntax, install steps, or JavaScript events. YanaQuickView has no JS event API.
