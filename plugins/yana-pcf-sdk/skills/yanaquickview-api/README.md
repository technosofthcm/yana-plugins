# yanaquickview-api

Auto-triggers on YanaQuickView manifest property lookups, configuration XML queries, error message lookups, and compatibility/limitations questions.

Keyword anchors: `quickViewConfigName`, `selectedQuery`, `FamilyTreeConfig`, `YanaQuickView manifest`, `QuickView config XML`, `xts_pluginconfiguration QuickView`, `CurrentRecordId`, `CurrentUserId`, `accordion section configuration`.

Does NOT cover install/embedding steps (route to `yanaquickview-install`) or functional how-to questions (route to `yanaquickview-manual`). YanaQuickView has no JavaScript event API.
